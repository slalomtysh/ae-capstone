# Roadmap (v1)

## Delivery Order (fixed)
1. Update project overview.
2. Complete foundational documentation pass.
3. Update feature specs.
4. Implement code.

## Runtime Baseline
- Angular 21
- Node.js v25.6.1

## Milestone 1: Foundations
- Initialize monorepo app structure.
- Create shared DTO contracts.
- Stand up Express API skeleton.

## Milestone 2: Core Experience
- Implement Team Selection with local storage persistence.
- Implement Live Games and Recent Games on Home screen.
- Implement Game View details and Home navigation.

## Milestone 3: Hardening
- Add caching, retries, and error handling.
- Complete unit/E2E/a11y test suites.
- Polish UI theme to sporty Material design.

## Definition of Done
- All required test gates pass.
- Specs are implemented and acceptance criteria are met.
